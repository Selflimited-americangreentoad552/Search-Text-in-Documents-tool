## 🧠 How It Works

1. **Indexing** – The tool scans your selected folder and reads the text content of all supported documents (DOCX, PDF, XLSX, TXT, etc.).
2. **Storage** – It builds a lightweight index of all words and their locations.
3. **Search** – When you enter a search term, the tool instantly finds all matching documents.
4. **Preview** – The tool shows you the exact lines where your search term appears.
5. **Export** – Save search results to CSV or HTML.

All processing is done locally. No data is sent anywhere.

## ⚠️ Common Problems & Solutions

### Problem: "Failed to open document"

**Solution:**
- Make sure the document is not password-protected.
- Check that the file is not corrupted.
- Try reopening the file.

### Problem: Search is slow

**Solution:**
- The tool indexes documents on first launch. Subsequent searches will be instant.
- If you have thousands of large PDFs, indexing may take a few minutes.
