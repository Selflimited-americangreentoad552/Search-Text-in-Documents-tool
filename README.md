## 📋 What this tool does
Many people store thousands of files on their computers. Finding information inside these files takes hours if you open them manually. This tool automates that process. It indexes your documents and allows you to perform full-text searches.

This application provides the following features:
*   Search across multiple file types including DOCX, XLSX, PDF, and TXT.
*   Find exact phrases or single keywords within documents.
*   View matches with surrounding text for context.
*   Process large folder structures with ease.
*   Operate locally on your machine for data privacy.

## 🔎 How to conduct a search
Once the application opens, you see a clean interface. Follow these steps to start your first search:

1.  **Select a folder:** Click the Browse button to choose the folder containing the documents you wish to search.
2.  **Enter your keywords:** Type the word or phrase you need to locate into the search box.
3.  **Choose file types:** Select the checkboxes for the specific file formats you want the tool to analyze. You can pick PDF, Word, Excel, or all of them.
4.  **Run the process:** Click the Search button. The tool displays a progress bar while it reads your files.
5.  **View results:** The main window populates with a list of files that contain your search terms. Click any file to see the specific lines where your keywords appear.

## 💡 Troubleshooting common issues
If you encounter trouble, use these solutions:

*   **Software will not open:** Ensure you have the .NET Framework installed. You can download it from the official Microsoft support page if necessary.
*   **Search yields no results:** Verify that the folder path is correct. Check that you selected the correct file extensions in the settings menu.
*   **High memory usage:** Processing many large files at once consumes system resources. If the app slows down, try searching one sub-folder at a time rather than an entire drive.
*   **Permision errors:** Ensure you have read access to the folders you selected. If a folder is restricted, the application cannot open the files within it to perform the lookup.

## 🔒 Data Privacy
This application runs entirely on your local machine. It does not send your data to external servers or cloud services. Your search queries and your document contents remain private. No log files leave your computer during the operation of this software.

## 🛠 Advanced settings
Users may want to adjust how the tool handles large volumes of data. You can access the settings menu by clicking the gear icon in the top right corner.

*   **Include subfolders:** Set this to true if you want the tool to enter every folder inside the main directory.
*   **Match case:** Enable this to force the search to distinguish between capital and lowercase letters.
*   **Index management:** If you change your files often, click the Re-index button to ensure the search results remain current.
